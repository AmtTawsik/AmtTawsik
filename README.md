## 📦 Open Source — @amtstack/envmaster

<div align="center">

### 🌌 EnvMaster — The Ultimate Environment Variable Toolkit

[![npm version](https://img.shields.io/npm/v/@amtstack/envmaster?style=for-the-badge&color=CB3837&logo=npm)](https://npmjs.com/package/@amtstack/envmaster)
[![docs](https://img.shields.io/badge/Docs-envmaster.amtstack.com-1B4FD8?style=for-the-badge&logo=google-chrome&logoColor=white)](https://envmaster.amtstack.com)

</div>

> Unlike regex-based tools, EnvMaster uses an **AST-powered compiler engine** that reads your code exactly the way Node.js does — guaranteeing **100% accuracy** for environment variable discovery, validation, and security auditing.

**What it does:**
- 🔍 **Auto-discovers** every `process.env` usage in your codebase using AST analysis
- ✅ **Validates** your `.env` file strictly before you deploy
- 🛡️ **Audits** secrets and blocks exposed keys in client bundles
- ⚡ **Works out of the box** with Next.js, Vite, Prisma, Monorepos, and more

```bash
# Try it instantly — zero install needed
npx @amtstack/envmaster doctor

# Add to your project
npm install @amtstack/envmaster
```
